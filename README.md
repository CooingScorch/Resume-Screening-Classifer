Steps to set up the system:

1. download lirbaires using the commands:
pip install -r requirements.txt

2. Copy an api key in Ai Studio and paste in app.py line 13

3. Run the clean.py to clean the dataset.

4. Run train.py to train the model

5. Run the baseline.py to show the BoW (baseline model) metrics

6. Run the app.py using command to run the system interface:
streamlit run app.py
